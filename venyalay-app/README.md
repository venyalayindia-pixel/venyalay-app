# VENYALAY App

India's Ritual Wellness Brand — mobile-first React + TypeScript + Tailwind prototype.

## Run locally

```
npm install
npm run dev
```

Open the local URL Vite prints (default http://localhost:5173).

## Build

```
npm run build
npm run preview
```

## Admin dashboard

Visit `/admin` — demo password: `venyalay-admin`

## Notes

- All cart, wishlist, orders, rewards, and ritual-tracker data persist to `localStorage` in the browser.
- Checkout is a mock flow — no real payment gateway is connected.
